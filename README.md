# Recipe Finder App

## Description
A React-based Recipe Finder application that allows users to search for meals and view detailed recipe information using TheMealDB API.

## Features
- Search recipes by name
- View recipe list with images
- View detailed recipe information
- Ingredients and preparation instructions
- Handles no search results

## Technologies Used
- React
- JavaScript
- HTML
- CSS / Tailwind CSS
- TheMealDB API
